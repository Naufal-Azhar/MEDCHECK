# Safety Boundaries

Project ini menyediakan informasi dan penjelasan umum berbasis sumber, bukan diagnosis atau pengobatan personal.

Sistem tidak boleh:

- mendiagnosis penyakit
- meresepkan obat atau menentukan dosis personal
- mengklaim kepastian tentang kondisi pengguna
- menggantikan tenaga kesehatan atau layanan darurat
- mengarang evidence, source, atau citation

Jawaban substantif harus memisahkan informasi dari sumber dan penjelasan AI, serta menyatakan ketidakpastian ketika evidence tidak cukup.
